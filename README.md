# SelRisk-Almaty

**Оценка риска схода селей и оползней в горах вокруг Алматы по гидрометеорологическим и сейсмическим данным.**

🌐 **Сайт-калькулятор:** https://dulattastanbay-dev.github.io/selrisk-almaty/ ·
[постер](https://dulattastanbay-dev.github.io/selrisk-almaty/docs/poster/poster.html) ·
[презентация](https://dulattastanbay-dev.github.io/selrisk-almaty/docs/slides/slides.html) ·
[статья](docs/article/article.md)

Проект строит **двухуровневую модель** риска для селеопасных бассейнов Заилийского
Алатау (Малая Алматинка, Большая Алматинка, Талгар):

1. **Подверженность (susceptibility) — «где».** Статическая модель (Random Forest)
   по признакам рельефа и близости к руслам и моренным озёрам оценивает, где в
   принципе возможен сход.
2. **Триггер (triggering) — «когда».** Временная модель (градиентный бустинг +
   классический порог «интенсивность–длительность» осадков) оценивает суточную
   вероятность схода по осадкам, снеготаянию, увлажнению и сейсмике.
3. **Итоговый риск = подверженность × вероятность триггера** — суточная карта
   риска по ячейкам и по бассейнам.

> **Почему так.** Полноценного открытого размеченного каталога сходов селей нет —
> это главная трудность темы. Поэтому пайплайн работает на **физически
> обоснованной синтетической выборке** (чтобы всё запускалось без закрытых данных)
> и одновременно на **реальных открытых данных** (живой каталог землетрясений
> USGS уже подключён; ERA5 и ЦМР — по инструкции). Реальная инвентаризация
> Казселезащиты и ERA5 подставляются в те же схемы — модели при этом не меняются.
> Это ограничение честно описано в статье (`docs/article/article.md`).

## Быстрый старт

```bash
pip install -r requirements.txt
python scripts/run_all.py          # данные -> обучение -> оценка (все графики)
python scripts/predict.py --date 2015-07-23   # оценка риска на дату + карта
```

Интерактивное демо (нужен `pip install streamlit`) — вероятность схода по дням
2016–2023 в процентах, та же откалиброванная модель, что на сайте:

```bash
streamlit run app/streamlit_app.py
```

Подгрузить реальный каталог землетрясений USGS (открытый API, без ключа):

```bash
python scripts/01_fetch_data.py    # затем снова run_all.py — сейсмика станет реальной
```

## Сайт-калькулятор (web/)

Статический сайт: пользователь вводит осадки, температуру, снег и магнитуду
землетрясения и получает **суточную вероятность схода селя (%)** по каждому
бассейну, вклад факторов и карту риска. Три режима:

- **Ввести вручную** — свои значения или готовые сценарии;
- **Архив 2016–2023** — любой день реальной погоды ERA5-Land, график ±45 дней;
- **Сейчас и прогноз** — живая погода [Open-Meteo](https://open-meteo.com) в тех же
  21 узлах сетки ERA5 + каталог землетрясений USGS, прогноз на неделю.

```bash
python scripts/export_web.py                           # после run_all.py: модель и данные -> web/data
python -m http.server 8000 --directory web             # открыть http://localhost:8000
```

Можно просто открыть `web/index.html` в браузере — сервер не нужен. Для публикации
достаточно выложить папку `web/` на любой статический хостинг (GitHub Pages,
Netlify). Нужен интернет: карта, погода и сейсмика загружаются онлайн.

Проценты на сайте и в Streamlit-демо даёт **откалиброванная логистическая
регрессия** по тем же признакам (+ бассейн): `train_calibrated_trigger()` в
`src/selrisk/models/triggering.py`, параметры и уровни опасности — в
`config.yaml` (`models.calibrated_trigger`). `train.py` сохраняет её в
`data/models/trigger_calibrated.joblib` и пишет колонку `trigger_prob_cal`.
Бустинг из `train.py` обучен с balanced-весами и почти запоминает дни событий
(≈1.0 на них и ≈0 на прочих), поэтому его выход нельзя показывать как «процент»;
он остаётся в научных экспериментах и картах `evaluate.py`. Логрег на holdout
2020–2023: ROC-AUC 0.98, ожидал 10.3 события при 7 фактических. Расчёт признаков
в `web/model.js` совпадает с Python на всех 8766 днях (`tests/test_web_parity.py`).

## Результаты (реальные данные: рельеф GLO-30 + осадки ERA5-Land 2016–2023)

Обучено и оценено на **реальных открытых данных**: рельеф Copernicus GLO-30,
суточные осадки/температура/снег ERA5-Land за 2016–2023 (96 месяцев), сейсмика
USGS. Метрики — **mean ± std по 8 seed** (`scripts/experiments.py`).

> **Исправление от 28.09.2026.** Суточные осадки ERA5-Land раньше агрегировались
> неверно (значение в 00 UTC — сумма за *предыдущие* сутки, и дождь дублировался
> на следующий день; осадки были завышены на ~46 %). После исправления в
> `era5.py` пайплайн перезапущен; ниже — новые метрики. Старые результаты
> сохранены в `backup_before_era5_fix/`.

| Модель | Метрика | Значение |
|---|---|---|
| Подверженность (RF) | ROC-AUC (пространств. CV) | **0.81 ± 0.01** |
| Подверженность (RF) | Average Precision | **0.81 ± 0.02** |
| Триггер (бустинг) | ROC-AUC (врем. holdout 2020–2023) | **0.91 ± 0.08** |
| Триггер (бустинг) | Average Precision | **0.18 ± 0.06** |
| Порог I–D осадков | recall / precision | ≈ 0.89 / 0.10 |

> **Почему AP низкий, а ROC-AUC высокий.** Сель-события — ~0.4 % дней (крайний
> дисбаланс). ROC-AUC показывает, что модель хорошо ранжирует опасные дни
> «наверх»; низкий AP отражает трудность точного порога при такой редкости — это
> честный режим для реальных данных и мотивация к сбору реального каталога сходов.
> В тестовом периоде всего 7 событий, поэтому разброс по seed велик.

**Ключевой вывод — абляция признаков триггера (реальные данные, seed 42):**

| Набор признаков | ROC-AUC | AP |
|---|---|---|
| полный | 0.94 | 0.29 |
| **без сейсмики** | 0.96 | 0.19 |
| **без осадков** | 0.90 | **0.011** (модель деградирует) |

Удаление осадков **обрушивает** качество (AP в 26 раз ниже), удаление сейсмики —
нет: ROC-AUC даже немного выше, а падение AP при 7 тестовых событиях нестабильно.
В важности по перестановкам лидируют `rain_3d` и `api`, сейсмические признаки = 0.
Бейзлайны: RF ≈ логрег для подверженности (0.81 vs 0.81). Вывод: **сейсмический
триггер вторичен, осадки — главный фактор**, что согласуется с природой селей
Алматы (прорывы моренных озёр и ливни, а не землетрясения).

Все карты и графики — в `data/outputs/` после `run_all.py`; интерактивная
карта — `docs/map/risk_map.html`.

## Данные

| Что | Источник | Статус |
|---|---|---|
| Осадки/температура/снег | ERA5-Land (Copernicus CDS) | ✅ реальные, 2016–2023 (96 мес.) |
| Рельеф (ЦМР) | Copernicus GLO-30 / AWS Terrain Tiles | ✅ реальные (без ключа), подключены |
| Землетрясения | USGS FDSN Event API | ✅ реальные, подключены |
| Каталог сходов | NASA COOLR / GLC (ArcGIS) | ✅ интеграция; покрытие ЦА разреженное |
| Ледниковые озёра | инвентаризация (шаблон) | ⚠️ приблизительно, заменить на GLIMS/ICIMOD |
| Метки сходов | синтетический процесс от реальных осадков | ⚠️ демо; заменить каталогом Казселезащиты |

### Переход на реальные данные

1. **Сейсмика** — уже реальная после `python scripts/01_fetch_data.py`.
2. **ERA5-Land** — реализовано. Нужно: (а) `~/.cdsapirc` с ключом CDS;
   (б) принять лицензию датасета на сайте CDS
   ([manage licences](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-land?tab=download#manage-licences));
   (в) `pip install cdsapi xarray netCDF4`; затем `python scripts/fetch_era5.py`.
   После этого `run_all.py` сам использует реальную погоду (осадки/температура/снег),
   снеготаяние считается по убыли SWE. ERA5-Land почасовой за годы качается долго.
3. **ЦМР** — положить GeoTIFF в `data/raw`, передать массив высот в
   `dataset.build_terrain_grid(dem=...)`. Формулы уклона/кривизны/TWI уже готовы.
4. **Каталог сходов** — заменить `data/events/historical_events.csv` реальной
   инвентаризацией (дата, бассейн, координаты очага). Тогда метки подверженности
   и событий станут реальными, а генератор выборки больше не нужен.

## Ограничения

- Демонстрационные метки (подверженность и события) **синтетические**, хотя и
  порождены физически осмысленной моделью; абсолютные значения метрик отражают
  восстановимость этой модели, а не реальную точность прогноза.
- Координаты озёр и часть дат сходов **приблизительны** и требуют сверки.
- Бассейны разделены по ближайшему центроиду (Вороной), а не по реальным
  водоразделам — при реальной ЦМР следует использовать границы водосборов.
