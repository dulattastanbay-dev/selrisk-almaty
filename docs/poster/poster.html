Историческое ранжирование селевых дней при неполной разметке

Не прогноз вероятности. Не система оповещения. Реальные события, прозрачная проверка, явные ограничения.

Вопрос

Помогает ли региональная погода отличать зарегистрированные селевые даты от фоновых дней лучше, чем один календарный сезон?

NOAA: отдельный опыт 1937–1991, 102 положительные даты, 85 с полными признаками. 152 полигона очагов не считаются границами водосборов.

Метод

Target сохраняется как 1/NULL. Отдельный индикатор показывает происхождение: дата каталога или допустимый фон, который может содержать незарегистрированные события.

  1. Исключить неопределённые интервалы и фон ±7 дней от известных событий.
  2. Взять признаки D−2 UTC и ранее: дождь, температура, накопленные окна, сезон.
  3. Обучить scaler и logistic regression только на train.
  4. Выбрать C только на validation; не переобучать на test.
  5. Сравнить с осадками за три дня и с одним сезоном.

Train 1981–2005 → validation 2006–2012 → test 2013–2020. Между погодными окнами 16-дневное исключение.

Проверка

POWER, отложенный период. Показатели относятся только к «запись каталога / выбранный фон».

Загрузка результатов…

Захват: доля зарегистрированных дат в верхней десятой части ранжирования. Не оценка полноты всех селей.

Вывод

Получен воспроизводимый региональный исследовательский прототип. Значительная часть разделения связана с сезонностью; статистическая значимость преимущества не установлена.

Нет истинных отрицательных, калибровки, проверки ложных тревог, внешнего пилота и подтверждённой оперативной доступности.
