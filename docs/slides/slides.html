SelRisk-Almaty

Оценка риска схода селей и оползней
в горах вокруг Алматы

Двухуровневая модель на открытых данных:
подверженность склонов (где) × вероятность триггера (когда) → карта риска.

1
Проблема

Алматы — под селевой угрозой

  • 1921 — катастрофический сель по М. Алматинке, сотни жертв.
  • 1963 — прорыв морены, уничтожение оз. Иссык.
  • 1973 — сель остановлен плотиной Медеу.

Деградация ледников → рост числа и объёма моренных озёр → растущая угроза прорывных селей (GLOF).

Нужна количественная, воспроизводимая оценка риска.

2
Идея

Разделяем задачу на два уровня

Подверженность
Random Forest
рельеф · русла · озёра
×
Триггер
бустинг + порог I–D
осадки · снег · сейсмика
=
Риск
суточная карта
по бассейнам

Почему так: у каждого уровня своя метрика и своя честная валидация — задача становится проверяемой, а не «красивой картой».

3
Данные

Только открытые источники

  • ERA5-Land — реальные осадки/температура/снег 2016–2023 (96 мес.).
  • Copernicus GLO-30 — реальная ЦМР → уклон, кривизна, TWI, сток D8.
  • USGS FDSN — каталог землетрясений (реальный).
  • NASA COOLR / GLC — каталог сходов; инвентаризация моренных озёр.

Открытого плотного каталога сходов нет — это главная трудность темы. Пайплайн работает на физически обоснованной выборке и реальных данных; реальная инвентаризация подставляется без изменения моделей.

4
Результат · где

Модель подверженности

ROC-AUC ≈ 0.81 (пространственная кросс-валидация).

Важнейшие факторы: уклон, высота, эродируемость пород, профильная кривизна, близость к моренным озёрам.

Максимум подверженности — на крутых склонах зоны формирования ниже моренных озёр.

5
Результат · когда

Порог «интенсивность–длительность»

Порог I = 10.3·D−0.18 отделяет триггерные дожди.

recall ≈ 0.89, но precision ≈ 0.10 — много ложных тревог.

→ поэтому переходим к ML-модели триггера.

Реальные осадки ERA5, среднее ± СКО по 8 seed. Высокий ROC-AUC при низком AP — крайняя редкость событий (~0.4 % дней, в тесте 7).

7
Ключевой вывод · абляция

Сейсмика — вторичный триггер

Без осадков: AP 0.29 → 0.011
Без сейсмики: ROC-AUC 0.94 → 0.96

На реальных данных: удаление осадков обрушивает качество (AP в 26 раз ниже), удаление сейсмики — нет. Важность сейсмики по перестановкам = 0.

Согласуется с природой селей Алматы: прорывы озёр (GLOF) и дожди, а не землетрясения.

8
Научная строгость

Устойчивость и честная оценка

  • Разброс по 8 seed (mean ± std) — не одно «удачное» число.
  • Бейзлайны: RF ≈ логрег (подвер.); триггер: бустинг лучше по AP, логрег — по ROC-AUC.
  • Абляция групп признаков — вклад каждого фактора.
  • Калибровка вероятностей (reliability, Brier).

Пространственная CV (подверженность) и временной holdout (триггер) — без утечки.

9
Применение

Обложной весенний дождь — 25.04.2019

ERA5: 50–52 мм за 3 дня на насыщенный грунт — сработали все три бассейна, риск до 0.98.

Максимум — в зонах формирования на крутых склонах ниже моренных озёр; долины и водоразделы — низкий риск.

10
Применение

Сайт-калькулятор вероятности селя

  • Ввести вручную — осадки, температура, снег, магнитуда → вероятность схода за сутки, %.
  • Архив 2016–2023 — любой день реальной погоды ERA5-Land.
  • Сейчас и прогноз — живая погода Open-Meteo + землетрясения USGS на неделю вперёд.
  • Карта риска по ячейкам 400 м и вклад каждого фактора.

Откалиброванная логистическая регрессия: на 2020–2023 ожидала 10.3 события при 7 фактических, ROC-AUC 0.98.
